# Sistema de Leilões

Sistema de leilões online desenvolvido para o
teste técnico Elite Dev da Verzel.

## Tecnologias

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL
- Socket.IO

## Funcionalidades previstas

- Autenticação de usuários
- Gerenciamento de leilões e lotes
- Lances em tempo real
- Carteira virtual
- Comprovantes de arremate
- Auditoria de lances

## Estrutura do projeto

- frontend: interface da aplicação
- backend: API e regras de negócio
- docs: documentação técnica
