# Arquitetura do Sistema de Leilões

## Visão geral

Aplicação Full Stack para gerenciamento de
leilões online.

## Frontend

React, TypeScript, Vite e Tailwind CSS.

## Backend

Node.js, Express e TypeScript.

## Banco de dados

PostgreSQL com Prisma ORM.

## Comunicação em tempo real

Socket.IO para atualização dos lances.

## Segurança

Autenticação JWT, senhas criptografadas
e autorização baseada em perfis.

## Organização

Arquitetura modular com separação entre
frontend, backend e documentação.
